Cara menjalankan program ada 2 cara:
    1. Menggunakan Tombol Play
        (a) Buka folder Source_Code
        (b) Klik file Search.java
        (c) Setelah file Search.java kebuka, klik tombol play (Run Java di bagian kanan atas)
        (d) Ketik query yang ingin anda cari di terminal 
    2. Menggunakan Terminal 
        (a) Buka terminal 
        (b) Pastikan terminal berada di path yg benar dengan direktori 
        (c) Di path blablabla\ProyekIR>, ketik javac Source_Code/*.java
        (d) Ketik java Source_Code.Search
        (e) Ketik query yang ingin anda cari di terminal
